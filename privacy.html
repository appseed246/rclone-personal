アクセスする情報と目的

本アプリは運営者本人のGoogle Drive上のファイル内容およびメタデータ（ファイル名、識別子、サイズ、更新日時など）にアクセスし、本人が指定した端末・保存先との同期、バックアップ、復元のために使用します。実際のアクセス範囲は、認可された権限とrcloneの設定に従います。

保存と管理

OAuth認証トークンはrcloneの実行環境で管理します。同期・バックアップ対象のデータは、Google Driveおよび本人が指定した保存先に保存します。処理ログにはファイル名や処理結果が含まれる場合があります。不要になったコピー、ログ、認証設定は本人が管理・削除します。

共有と利用の制限

Googleユーザーデータを第三者に販売したり、広告配信、第三者向けの分析、汎用AI・機械学習モデルの学習に使用したりすることはありません。同期に必要なGoogleと本人が指定した保存先への通信を除き、第三者への提供は行いません。

Google APIから取得した情報の利用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに準拠します。

アクセスの取り消しと削除

本人はGoogleアカウントの接続管理から本アプリへのアクセスを取り消せます。取り消しだけでは保存済みのファイルは削除されません。保存先のコピー、ログ、rcloneの認証設定は、必要に応じて本人が別途削除します。

このウェブサイトについて

この説明サイトにはアクセス解析、広告、独自のCookie、入力フォームを設置していません。ホスティング提供者のGitHubは、サイト提供に伴う情報を独自のプライバシーステートメントに従って取り扱います。
